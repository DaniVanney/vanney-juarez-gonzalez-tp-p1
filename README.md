# Vanney-Juarez-Gonzalez-tp-p1
# Delivery Rush

Integrantes: Daniel Vanney, Agustina Juarez

Materia: Programación I, segundo semestre de 2026.

Descripción: Juego de reparto de pedidos desarrollado en Java. Hay que retirar pedidos en negocios y entregarlos en casas, evitando enemigos y bombas. Se gana al completar cinco entregas.

Ejecución: Abrir el proyecto mediante el método tick() de Juego.java y ejecutar la clase juego.Juego. Mantener entorno.jar y las imágenes en la carpeta principal del proyecto.

Controles: WASD o flechas para moverse. Clic izquierdo para disparar. Clic derecho sobre el negocio o la casa para retirar o entregar un pedido, estando sobre la flecha indicada.
